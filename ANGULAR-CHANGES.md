# Angular adapter changes

| What                                                                                                                                                  | Why                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `provideTanStackQuery` accepts a query-client factory or injection token, and evaluates factories in an injection context.                            | Create one client per Angular application/request and allow factories to use `inject()`, avoiding shared server-side state.                               |
| `configureQueryClient` adds TransferState hydration by default; opt out with `withNoQueryHydration()` or customize the key with `withHydrationKey()`. | Match Angular's HTTP client default and reuse server-fetched data in the browser.                                                                         |
| Query and mutation results expose lazily created, memoized field signals while forwarding imperative methods without reactive tracking.               | Allow references such as `query.data` to be captured without evaluating query options too early, including options that read required input signals.      |
| Base queries auto-track non-function observer properties before exposing the signal proxy.                                                            | Keep Query Observer property notifications connected even when a lazy field signal is read later.                                                         |
| Angular 20 is the minimum supported version.                                                                                                          | Follow Angular's active/LTS support policy and use Angular 20 APIs without retaining Angular 19 compatibility paths.                                      |
| Query results expose an Angular Resource-compatible interface.                                                                                        | Provide first-class integration with Angular APIs such as Signal Forms while retaining Query caching, cancellation, retries, and stale-time behavior.     |
| Query, parallel-query, and mutation work is registered with Angular's pending-task system.                                                            | Let SSR stabilization wait for active work without blocking on paused or disabled queries.                                                                |
| A shared `injectQueryLifecycle` helper owns pending-task registration, destruction tracking, and `DestroyRef` cleanup.                                | Apply the same idempotent lifecycle behavior across queries, query arrays, and mutations, including on Angular 20 where `DestroyRef.destroyed` is absent. |
| Infinite-query results support status-based narrowing, and defined infinite initial data cannot be `undefined`.                                       | Make `data()` narrow correctly after status checks and keep defined-result contracts sound.                                                               |
| `injectQueries` has reactive options, observer updates, tuple inference, and `combine` behavior.                                                      | Make the parallel-query API functional at runtime and accurately typed.                                                                                   |
| `injectQueries` gives every result field-level signals and a Resource.                                                                                | Bring parallel queries to the same Angular-native result shape as single queries.                                                                         |
| `injectQueries` accepts its optional injector as `{ injector }`.                                                                                      | Keep explicit-injector usage consistent with the other injection APIs and leave room for future options.                                                  |
| Query features provide an extension mechanism for query-client configuration.                                                                         | Let hydration, persistence, and devtools compose through Angular providers without expanding the core provider API.                                       |
| Angular devtools moved from an adapter entry point to a separate library.                                                                             | Prevent unused devtools imports from generating deployment chunks and keep devtools dependencies out of the core adapter.                                 |
| Devtools use conditional exports with no-op production defaults and explicit production entry points.                                                 | Exclude the panel from production bundles by default while still allowing intentional production use.                                                     |
| Devtools are browser-only and deduplicated across child and lazy-route injectors.                                                                     | Allow route-level providers without mounting multiple panels.                                                                                             |
| Devtools options run in an injection context and the panel mounts during the `afterNextRender` write phase.                                           | Allow direct `inject()` calls in configuration and schedule DOM writes in Angular's intended render phase.                                                |
| Persistence restores and subscribes only in the browser, and participates in Angular pending tasks.                                                   | Avoid server-side storage access and prevent stabilization before restoration completes.                                                                  |
| `ng add` configures an SSR-safe root query-client factory and installs and configures devtools.                                                       | Provide a complete default setup while keeping runtime configuration in normal Angular providers.                                                         |
| The schematic embeds the adapter and devtools package names and the devtools package's current version during the package build.                      | Install the correct devtools release even when its version differs from the adapter, without reading package metadata in the consuming application.       |
